# 旅游攻略自动化

这是我的旅游攻略自动化项目的工作目录。

## 这个仓库是干什么的

这个仓库的作用不只是"存代码"，更重要的是**存"确认点"**：

- 每次我（AI）写好一段代码、你说"满意"，就会产生一个**确认点**（存档）；
- 确认点会同时保存到你的电脑（Git）和云端 GitHub；
- 之后任何时候你反悔，都能一句话退回某个确认点。

具体的操作说明看 → [Git使用说明.md](Git使用说明.md)
已经存了哪些档看 → [存档点记录.md](存档点记录.md)

## 目录说明

```
旅游攻略自动化\
├─ README.md            ← 你正在看的这个文件
├─ Git使用说明.md         ← 大白话操作说明（小白看这个）
├─ 存档点记录.md          ← 历次确认点清单
├─ .gitignore           ← 告诉 Git 哪些文件不要上传
└─ tools\
   ├─ save-point.ps1   ← 打一个确认点（存档 + 上云）
   └─ rollback.ps1     ← 退回某个确认点
```
